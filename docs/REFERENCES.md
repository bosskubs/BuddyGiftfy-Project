## เทคโนโลยีและเอกสารประกอบ

- [Frankfurter](https://frankfurter.dev/) — บริการอัตราอ้างอิงงบของขวัญ ตัวอย่าง [THB/USD](https://api.frankfurter.dev/v2/rate/thb/usd) และ [THB/EUR](https://api.frankfurter.dev/v2/rate/thb/eur) ผลเรียกจริงและการทดสอบ error/retry อยู่ในหลักฐานรุ่นปัจจุบัน
- [MySQL 8.4 Downloads](https://dev.mysql.com/downloads/mysql/8.4.html) และ [คู่มือติดตั้ง MySQL](https://dev.mysql.com/doc/refman/8.4/en/binary-installation.html)
- [Node.js HTTP](https://nodejs.org/api/http.html) และ [การอ่าน environment file](https://nodejs.org/api/cli.html#--env-filefile)
- [mysql2](https://github.com/sidorares/node-mysql2) — driver ที่ API ใช้เชื่อม MySQL
- [Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API) — browser เรียกบริการด้วย JavaScript
- [Postman/Newman](https://github.com/postmanlabs/newman) — รัน collection ทดสอบบริการ
- [Playwright](https://playwright.dev/) และ [axe](https://github.com/dequelabs/axe-core-npm) — ทดสอบ browser และการเข้าถึงอัตโนมัติ
- ฟอนต์จากชุดงานออกแบบ: Inter, Noto Sans Thai, Nothing You Could Do, Passions Conflict, Cormorant Garamond และ Libre Baskerville; ดูชื่อ family ที่ [Google Fonts](https://fonts.google.com/) ไฟล์ที่ใช้จริงยังอ้างชุดออกแบบที่ได้รับมา
- ไอคอนเป็น inline SVG paths ในซอร์ส ไม่เรียก icon CDN

## การใช้ Generative AI

ใช้ **OpenAI Codex** ช่วยวางแผน เขียน/ปรับโครงสร้าง/แก้โค้ด ย้ายฐานข้อมูล สร้างและรันทดสอบอัตโนมัติ รวมทั้งเตรียมคู่มือและร่างรายงาน ซอร์สและผลทดสอบบอกขอบเขตที่สร้างและตรวจจริง ไม่อ้างว่าสมาชิกทุกคนเขียนหรือตรวจทุกไฟล์ด้วยตนเอง และไม่มีการลงนามหรือกำหนดสัดส่วนผลงานแทนสมาชิก

รายงานระบุรูปแบบการใช้ตามโจทย์ ได้แก่ ระดมความคิด ร่างชิ้นงาน สรุปเนื้อหา เรียบเรียง/แปลเอกสารเป็นภาษาไทย แก้ไข/ตรวจสอบโค้ด เขียนโค้ด และเตรียมเอกสาร/การทดสอบ เว็บไซต์ไม่ได้เชื่อม OpenAI API เป็นฟีเจอร์ จึงไม่ได้เลือก “ใช้ AI เป็นส่วนหนึ่งในผลงาน” ในความหมายนั้น สมาชิกควรอ่านและรับรองข้อความตามการใช้จริงของทีมก่อนส่ง
